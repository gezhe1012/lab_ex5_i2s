# 工程验收清单

## 1. 静态检查

- [ ] `.al` 工程引用所有新增 `.v` 文件，路径有效且无重复源文件。
- [ ] 顶层模块端口与 `pin.adc` 一致。
- [ ] 没有误改厂商加密源或IP包装文件。
- [ ] 所有跨时钟事件具有同步器、FIFO或握手。
- [ ] RGB、DE、VS、SOF、行尾信号的流水线延迟一致。
- [ ] SDRAM读缓冲只在帧边界切换。
- [ ] 算术结果有明确位宽和饱和/截断策略。

## 2. 构建检查

- [ ] TD `read_design`/elaborate 成功。
- [ ] RTL和门级优化成功，没有由本次修改产生的 ERROR。
- [ ] 新增 WARNING 已逐条判断，不隐藏位宽错误、锁存器或未驱动关键信号。
- [ ] 布局布线成功。
- [ ] bitstream成功生成，时间戳晚于最新HDL修改。
- [ ] 记录 LUT、寄存器、BRAM、DSP、PLL 使用量。
- [ ] 记录视频、SDRAM、SD和音频时钟域的时序结果。

## 3. 基础功能上板

- [ ] FAT32 TF卡可扫描到合法BMP。
- [ ] 首图加载前画面可控，加载后显示方向和RGB通道正确。
- [ ] KEY1每次只切换一张，按键抖动不导致连续跳图。
- [ ] KEY2可开启/关闭自动轮播。
- [ ] 连续轮播无撕裂、半帧、花屏或状态机死锁。
- [ ] HDMI_B输出48 kHz测试音，接收端无持续爆音或周期性断音。
- [ ] 断电重启后无需PC下载即可自动运行。

## 4. 扩展功能上板

### 扩展1

- [ ] OSD包含动态内容。
- [ ] 至少一个图层可见Alpha混合效果。
- [ ] 字幕移动平滑，字符不越界或闪烁。

### 扩展2

- [ ] 手动和自动切图均触发转场。
- [ ] 转场期间不显示未写完的新帧。
- [ ] 缓冲切换发生在黑场或帧边界。

### 扩展3

- [ ] 至少测试横图、竖图和非640×480图片。
- [ ] 宽高、像素偏移、位深、压缩方式验证正确。
- [ ] 缩放策略与预期一致，无读地址越界。

### 扩展4

- [ ] 每个控制键/拨码具有正确管脚和防抖/同步。
- [ ] 亮度和对比度调节实时生效并正确饱和。
- [ ] OSD数值与实际寄存器一致。

### 扩展5

- [ ] 波形或频谱随音频样本变化。
- [ ] 音频可视化不会破坏原HDMI音频播放。
- [ ] 音频到视频域的多位数据传输稳定。

## 5. 长稳测试

- [ ] 自动轮播至少30分钟。
- [ ] 重复按键操作至少100次。
- [ ] 热插拔显示器后能够恢复。
- [ ] 使用损坏或不支持的BMP时系统能够跳过或恢复。
- [ ] 至少进行10次冷启动并记录失败次数。

工具构建通过不等于上板验收通过。最终答复应分别列出“工具已验证”和“仍需实机验证”。
