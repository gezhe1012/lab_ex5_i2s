# 可复制的总提示词

将下列提示词复制给 Codex，并根据需要修改方括号内容。

```text
先读取并遵循当前工程中的 `./complete-hx4s20c-hdmi-project/SKILL.md`；如果该 Skill 已安装到 Codex，则使用 `$complete-hx4s20c-hdmi-project`。完成当前工作区中的 HX4S20C HDMI 多媒体赛题工程。

目标：
1. 对照《赛题解析一.pptx》建立基础要求和扩展要求1～5的完成矩阵。
2. 保留已经工作的 TF卡BMP读取、SDRAM双缓冲、HDMI显示、按键切图、自动轮播和48 kHz HDMI音频。
3. 完成所有尚未实现或仅部分实现的项目：
   - 动态OSD、Alpha图层、Logo或标语；
   - 淡入淡出或滑动转场；
   - 不同分辨率BMP解析与缩放适配；
   - 亮度/对比度实时调节并在OSD显示数值；
   - 随24-bit PCM变化的波形或频谱可视化。
4. 将新增Verilog加入Tang Dynasty工程，完成综合、布局布线和bitstream生成。
5. 给出需要执行的上板验收步骤，不能把工具构建等同于实机通过。

实施要求：
- 先检查现有源码、工程文件、约束、最近构建日志和已有改动，不要从头重写可工作的链路。
- 以可综合Verilog实现，不使用当前工程未启用的SystemVerilog语法。
- 跨时钟域必须使用FIFO、同步器或toggle握手。
- 新帧完整写入后才能提交；显示缓冲只能在帧边界或黑场切换。
- 新增像素流水线时保持RGB、DE、VS和AXI-Stream边界对齐。
- 缩放、Alpha、亮度、对比度和音频分析采用明确位宽的定点运算，并处理饱和和地址边界。
- 不得猜测板载按键或拨码管脚。若文档中没有准确映射，完成与管脚无关的逻辑并明确列出所缺信息。
- 不修改厂商加密HDMI/SDRAM IP，除非确有必要且说明原因。
- 每完成一个阶段就运行结构检查和TD综合；最终运行布局布线及bitgen。
- 不因已有.bit文件而宣称构建成功，必须核对生成时间和本次日志。
- 遇到原工程已有的时序负裕量，要定位具体路径并与旧报告比较，不要笼统忽略。

交付内容：
- 已修改和新增的源文件；
- 已更新的.al/.prj工程引用；
- 最新.bit文件；
- 要求完成矩阵；
- 综合资源和关键时序摘要；
- 实机测试清单与尚未验证的风险。

除非缺少管脚映射、外部硬件或会改变总体架构的必要选择，否则直接推进实现，不要只给方案或停在分析阶段。
```

## 分阶段提示词

只完成某一阶段时，可使用：

```text
先读取 `./complete-hx4s20c-hdmi-project/SKILL.md`（已安装时使用 `$complete-hx4s20c-hdmi-project`），仅完成[扩展要求编号和名称]。先确认该要求在当前源码中的真实状态，再实现、集成并运行对应级别的TD验证。保持其他已工作功能不回退，并给出上板检查步骤。
```
